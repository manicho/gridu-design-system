# gridu-design-system

Shared design system for the **gridu** ecosystem: design tokens, principles, and components
consumed by [gridu-web](https://github.com/manicho/gridu-web) (dashboard) and
[gridu-landing](https://github.com/manicho/gridu-landing) (marketing site).

Part of the **Product Identity Refresh** epic — see
[`epic-product-identity-refresh.md`](https://github.com/manicho/gridu/blob/main/docs/planning/epic-product-identity-refresh.md)
in the `gridu` repo for the full tracker across all three repos.

## Workflow

This repo is driven by [Spec Kit](https://github.com/github/spec-kit). Each feature follows:

```
/speckit-specify → /speckit-clarify → /speckit-plan → /speckit-tasks → /speckit-analyze → /speckit-implement
```

Specs live under `specs/`. Project principles, once defined (Feature 02), live in
`.specify/memory/constitution.md`.
